# Support

Use the [documentation](docs/index.md) and
[issue tracker](https://github.com/altophp/tree/issues) for usage questions and bugs.

Include PHP and package versions, the provider or parser used, a small explicit
input, printer options if relevant, and the expected and actual output. State
whether paths come from strings, a directory, or Git. For Git issues, include
the Git version, relevant refs, and error message.

Replace private filenames and contents with a minimal synthetic tree before
sharing a report. For feature requests, describe the hierarchy operation and
the resulting tree you need.
